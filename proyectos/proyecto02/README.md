El proyecto dos es una muestra de varios métodos estenográficos. 
El primero de ellos, pide al usuario un mensaje y un índice, índice con el cual evaluaremos todas las palabras presentes en el texto y uniendo las letras resaltadas lograremos encontrar el mensaje oculto.
El segundo método, encuentra un mensaje oculto dado un texto con espacios libres al final de este, y el número total de espacios adicionales presentes en el texto será nuestro índice para evaluar las palabras.
En el tercer método, se le pide al usuario un texto y un nombre. Ignorando espacios, signos de puntuación y sin hacer distinciones entre mayúsculas y minúsculas, debemos de hacerle saber al usuario si el nombre proporcionado está o no presente en el texto.
Con el cuarto método lo que se hace es construir un mensaje oculto dado otros dos previos similares, pero con distinciones en algunas palabras, será uniendo estas palabras distintas que sabremos el mensaje escondido.
El quinto y último método es muy similar al cuarto, pero con la distinción de que no serán las palabras distintas las que formen el nuevo mensaje, sino, solo las letras que sean distintas entre las palabras de los dos primeros textos originales.

PASOS PARA EJECUTAR EL PROGRAMA.

1. Ubicarse en su terminal con la ruta en donde se encuentra este archivo.
2. Compilar el código con: javac Esteganografia.java
3. Ejecutar el código con: java Esteganografia
4. Seguir las indicaciones propias del programa para obtener los resultados esperados.
